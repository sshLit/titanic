# Titanic

Соревнование [Titanic](https://www.kaggle.com/c/titanic) на Kaggle, финальный проект по классическому ML.
Лучший результат на 5 фолдах у LightGBM, 0.850. Ансамбли его не обогнали.

## Запуск

```bash
pip install -r requirements.txt
kaggle competitions download -c titanic -p data
tar -xf data/titanic.zip -C data
python main.py
```

Нужны API-токен Kaggle и scikit-learn 1.8 или новее (в старых `l1_ratio` у логрега игнорируется).
Прогон около 2 минут, результаты и сабмиты в `outputs/`.

Настройки в `config.py`, их можно менять из командной строки:

```bash
python main.py only=[catboost,lightgbm] models.knn.grid.n_neighbors=[5,15]
```

## Файлы

- `config.py` - модели, сетки параметров, ансамбль, абляция
- `main.py` - пайплайн: сетки на 5 фолдах, абляция, ансамбли, сабмиты
- `data.py` - загрузка, новые признаки, препроцессинг
- `utils.py` - модели, кросс-валидация, метрики, ансамбли
- `mlp.py` - нейросеть на PyTorch
- `eda.ipynb` - EDA и разбор результатов

## Что сделано

- Новые признаки: обращение, палуба, размер семьи, люди на билет, цена на человека, пол вместе с классом.
- Препроцессинг: `Age` по медиане `Title`, логарифм `Fare`, скейлинг, one-hot. Всё внутри `Pipeline`, чтобы не было
  утечки между фолдами.
- Валидация: StratifiedKFold на 5 фолдов, для каждой модели перебор сетки.

## Результаты

| Модель | Accuracy |
|---|---|
| Линейная регрессия, порог 0.5 (бейзлайн) | 0.824 |
| Логистическая регрессия | 0.834 |
| Дерево решений | 0.836 |
| KNN | 0.837 |
| Нейросеть (MLP) | 0.838 |
| Random Forest | 0.840 |
| XGBoost | 0.847 |
| CatBoost | 0.849 |
| LightGBM | 0.850 |

Ансамбли: голосование 0.846, стекинг через Ridge 0.845, через LinearRegression 0.843, среднее 0.842.

## Выводы

- Разница меньше 0.01 - шум: std по фолдам около 0.015.
- Новые признаки дали логрегу +3.9 п.п., бустингам почти ничего.
- Для логрега one-hot лучше ordinal на 3.5 п.п.
- Нейросеть (0.838) на 891 пассажире не лучше простых моделей.
- Ансамбли не помогли: модели ошибаются на одних и тех же пассажирах.
- Один holdout-сплит дал 0.810 против 0.850 на 5 фолдах, одному сплиту верить нельзя.
